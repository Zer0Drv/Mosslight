# 苔灯镇 · Mosslight

在长夜的林间种光、收露，修复苔灯，让归途重新亮起。

这是一款以“经营明暗”作为核心的 2D 像素经营游戏。目前可体验第一片林间灯圃：种植两类植物，安排光照，收集材料，修好两盏旧灯。

## 运行

- 引擎：Godot **4.7.2**，标准版，GDScript；本机目录 `D:\Godot_v4.7.2`。
- 导入本目录的 `project.godot`，按 **F5** 运行。
- 或运行 `powershell -ExecutionPolicy Bypass -File tools\run.ps1` 打开编辑器；`-Mode Play` 直接游玩，`-Mode Check` 运行检查。

## 第一片灯圃

| 植物 | 生长条件 | 成熟时间 | 收获 |
| --- | --- | --- | --- |
| 月苔 | 位于固定苔灯的光域之外 | 18 秒 | 3 露滴 |
| 灯铃 | 位于一盏点亮的苔灯光域内 | 24 秒 | 3 灯孢 |

初始有一盏亮灯、两盏待修复的旧灯。每修一盏需要 **6 灯孢 + 4 露滴**，目标是把三盏灯全部修好，重新连通林间灯路。

按 **Tab** 查看每格的明暗，再选择植物。开关已有苔灯会改变附近的生长条件：不适宜时植物暂停生长，条件恢复后继续，不会枯死。成熟植物不再受光照影响。

种子免费；种错可移除重种。露滴既是修灯材料，也可以用来促长：每次 1 露滴提高 35% 生长进度，但不能代替适宜光照。固定苔灯不消耗燃料；角色手里的小灯只用于照路和人物视觉，不改变作物光照。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 种植、收获、开关或修复面前的灯 | E / 空格 |
| 选择月苔 / 灯铃 | 1 / 2，也可点击底部种子卡 |
| 消耗 1 露滴促长 | Q |
| 移除未成熟的植物 | R |
| 显示 / 隐藏光域 | Tab |
| 静音 / 恢复声音 | M |
| 暂停 / 继续 | Esc |
| 切换全屏 | F11 |

面前的格子或灯会高亮，右下显示当前操作与条件。暂停期间植物停止生长。

## 美术与声音

### 当前采用的美术方向：原版 A/B/C

按用户选择，恢复第一版 A/B/C 为主要美术参考，保留各自的造型与氛围特色。后续制作以共同的像素语言、基础人物比例和交互规则维持一致性，允许不同服饰、建筑和地区有自己的轮廓。当前运行画面仍为程序像素样片；概念图尚未拆分为正式角色、图块或动画素材。

| 方向 | 用途 | 概念图 |
| --- | --- | --- |
| A · 奶油绘本 | 更细致的剧情 CG、开场与结尾关键画面、章节插画、过场演出 | [A 概念图](assets/concepts/a-storybook-cg.png) |
| B · 团子苔林 | 日常游玩的基础风格：镇子、家园、普通森林和常住 NPC | [B 概念图](assets/concepts/b-dumpling-forest.png) |
| C · 糖果星夜 | 幻想地区、月夜花园、特殊植物与精灵 NPC；保留原版人物为可选外观参考 | [C 概念图](assets/concepts/c-candy-starlight.png) |

B 与 C 共用角色基础头身比例、像素尺寸、轮廓处理、物件尺度和交互标记。帽子附加的高度不应被误当成身体比例变化。圆帽、尖帽、绒球、不同服装配色，以及圆苔顶、卷曲屋顶都可以作为不同服饰或建筑类型存在。C 保留原版蓝紫、薄荷荧光与星形装饰，不必收敛为 B 的简单换色。场景交界通过共有植物、石路与灯具逐渐过渡。精灵类 NPC 和星夜装扮也可以出现在普通聚落中。

固定苔灯以石座、苔顶、暖杏灯室及光域预览共同标识，只有这类灯具影响作物生长。手提灯、窗灯和普通装饰灯也可以发暖光，但不改变种植条件；蓝紫荧光用于环境点缀。两种地区维持一致的交互提示与光域预览，不能仅凭光的颜色判断功能。

A 保留第一版更细致的绘本气氛，用于剧情 CG、章节插画和过场演出。CG 表现同一角色或地点时，应与游戏中实际采用的服饰、建筑特征对应；原 A 的木屋可以作为独立建筑参考，不要求所有房屋都变成 B 的圆屋。适合先制作静态 CG，再以独立前景、背景、角色、雾气与光效图层做视差、轻微运镜和呼吸式灯光；完整角色动作仍需分层绑定或逐帧动画。现有 A 图是画面参考，不是已完成的动画文件。

参考图使用内置 image_gen 生成，三张原图均已无损归档。生成提示词与用途记录在 `assets/concepts/manifest.json`。该目录包含 `.gdignore`，参考图不会被作为运行时素材导入。

### 原版 C 人物：保留为可选外观方向

原版 B 的苔绿圆兜帽与原版 C 的蓝紫尖帽、桃色绒球和星夜衣装均保留。优先考虑作为同一主角的两套外观，也可以在后续角色创建时作为初始外观预设；目前尚未实现换装或角色选择功能。

| 外观候选（暂称） | 保留特征 | 参考 |
| --- | --- | --- |
| 苔林装 | 苔绿圆兜帽、桃色领巾、温暖自然的配色 | [原版 B](assets/concepts/b-dumpling-forest.png) |
| 星夜装 | 蓝紫尖帽、桃色绒球、原版 C 的衣装与可爱轮廓 | [原版 C](assets/concepts/c-candy-starlight.png) |

- 作为**换装**：共用脸部识别特征、基础身体比例、动作节奏和碰撞尺寸，允许帽型、披风、饰品与颜色明显不同；服饰不因进入另一地区而自动变化。
- 作为**初始外观选择**：可以提供两种预设，仍属于同一主角的外观选择，不自动代表不同职业、能力或剧情。
- 如果将来设为**独立可选角色或 NPC**，再补充其姓名、性格、脸部或发型区别与叙事定位；目前没有将这一方案定为独立角色系统。
- 剧情 CG 应对应角色当时的外观；服饰方案的具体获取方式和动画素材在后续制作时确定。

`assets/concepts/consistency-v1/` 保留为历史试验。用户更喜欢第一版的效果，因此本组不再作为主要美术参考，也不再要求新参考图都使用该组的圆帽、苔绿衣装和同一栋圆屋。历史图像和生成提示词不删除，见 [归档记录](assets/concepts/consistency-v1/manifest.json)。

### 当前样片

- 幽蓝夜色、苔绿植被、暖杏灯光；程序绘制的原创像素林地、苔顶木屋、石板小径、月色水池、菌类和蕨叶。
- 兜帽巡灯人，独立的月苔与灯铃生长形态；灯晕、薄雾、萤火与收获微粒。
- 640 × 360 逻辑分辨率、默认 1280 × 720 窗口，整数缩放与最近邻过滤。
- 静态环境与动态效果分层，静态绘制命令缓存，动态世界以有限频率重绘。
- 原创合成的林间环境循环及种植、收获、修灯音效。生成方式见 `assets/audio/README.md`。

## 存档

植物、生长进度、修灯状态、资源、选中种子与静音设置会保存在：

`user://mosslight_garden_v1.json`

游戏操作后和生长期间定期保存，关闭游戏时再次保存。每次覆盖保留上一份 `.bak`；主档损坏或缺失会尝试恢复备份。主备均无效时，以初始灯圃进入但不覆盖原档。暂停不推进生长，离线不推进生长，重新进入从林间出生点开始。

Headless 检查自动禁用真实玩家存档。开发时可在命令行追加 `-- --fresh-garden` 运行不读写存档的新灯圃。

## Godot AI MCP

项目已启用 Godot AI **4.3.1** 插件。本机 Codex 在 `C:\Users\Administrator\.codex\config.toml` 注册了：

```toml
[mcp_servers.godot-ai]
command = 'C:\Users\Administrator\.local\bin\godot-ai.exe'
args = ["attach", "--port", "8000", "--ws-port", "9500"]
```

保持 Godot 图形编辑器打开，插件连接本机后端，客户端通过 `attach` 接入。新增或修改配置后，在桌面应用的「设置 → MCP servers」重启该连接。已验证当前聊天能直接调用编辑器状态、场景树、运行调试和截图工具。

## 检查

```powershell
powershell -ExecutionPolicy Bypass -File tools\run.ps1 -Mode Check
```

检查覆盖明暗生长、资源收支、修灯分支、重复收获保护、快照验证、真实文件备份恢复，以及主场景输入、移动、碰撞和暂停。日志位于 `logs/`，测试不触碰玩家的真实存档。

当前是可玩的方向样片，小屋和池塘不能进入或采集；尚未加入 NPC、天气季节、完整背包、交易和更大的地图。
