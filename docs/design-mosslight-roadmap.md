## 1 当前基础与目标

当前`main`是一片可玩的灯圃：49格、两种作物、三盏固定灯、基础明暗生长、资源和v1存档。角色手灯目前只作视觉照明。NPC、时间季节、五区、冲刺、守夜、融合附痕和灯下模式属于目标设计。M0分支存在但未合并，实际状态见建造计划。

核心体验是经营明暗：玩家选择在哪里种、怎样布光、何时向远处走。没有角色等级、装备词条或强制战斗；玩家可以种植、守夜或混合游玩。

已选的第一步是切片A：12格、两种作物、三盏灯、今日页和灯下陪伴。起调参数见数值表；切片范围不扩大到所有已规划系统。

## 2 三条护栏

### A 可选玩法不得卡住进度

- 不守夜必须能达成全部主线和叙事完成度；不种植也必须有资源推进路线。
- 守夜可给夜露等可兑换奖励，但不能垄断主线必需材料。旧“守夜只给装饰”与双轨经济不相容，不再适用。
- 核心动作不以好感、连招、完美闪避或高评级为门槛。每个解锁至少有一条不依赖操作技巧的途径。
- D01已采纳：第一日黄昏在母灯附近岔路开放基础守夜，不要求先种地或修灯；实际闭环仍须按新档路线验证。

### B 战斗损失与经营状态隔离

- 局内灯火、弹药、遮蔽物损耗使用镜像；不会损坏玩家真实作物、扣掉镜像对应的真实露滴或回退修灯进度。
- v16已选择战斗产田，结算允许明确列出的正向结果，不能继续写“任何字段都零写入”。
- 夜露、余温、挂露、新耕地、图鉴/评级分别定义来源和结算。局内不能直接把整个镜像覆盖回经营状态。
- D02已采纳临时造田：夜间结算后保留一个完整白昼，到期封床保株；胜/败/弃提交及去重方案见[冲突处理方案](issue-resolution.md)第4节。

### C 选择可恢复

- 灯谱免费重置；融合探索失败不销毁配方材料，试验成本需在操作前可见。
- 借光不能到达未亲自探索的位置；不会提供免费无限传送。
- 作物条件不适宜时暂停，不枯死；过季约定变旧，不判失败。
- 存档损坏、迁移失败、高版本档均保留原文件，不能靠覆盖初始化“修复”。

## 3 系统设计

### 3.1 双轨经济

| 路线 | 资源来源 | 推进方式 |
| --- | --- | --- |
| 种植 | 月苔产露滴、灯铃产灯孢；夜苔产夜露 | 修灯、探索、与NPC交易 |
| 守夜 | 夜露及明确的结算奖励 | 兑换修灯材料或等价支付，兑换不能卡住任一种材料 |
| 混合 | 两侧来源 | 自由选择当日活动，共享世界进度 |

露滴、灯孢、夜露是三种资源；灯芯屑是满灯火凝积的合成材料，不新增货币体系。兑换率、夜露奖励和逐灯成本须按新A1一起重算；旧“每灯20夜露”和旧6+4成本不能继续直接套用。

纯种植/混合/纯守夜原时长比例1.00/1.15/1.30是体验目标，不是已验证结果。余温降低准备成本；不得据未实测比例反推玩家必须做的操作。数值主定义见[数值表](balance-tables.md)。

### 3.2 光照与作物判定

基准固定灯光域半径78px，格尺寸16px。视觉灯晕与生长判定分离；装饰灯和环境星点不自动成为有效光源。

工程上至少区分：

| 信息 | 用途 |
| --- | --- |
| 物理光强`intensity` | 普通深影、暖光、半光带的基础判断 |
| 光源性质/来源 | 暖杏、月青、倒影的区分；星铃检查双光，不能只检查总亮度 |
| 附痕授予的条件 | 二向痕等显式条件，能够表达同格阴阳，不要求单一数值同时小于0.15又大于0.6 |
| 土壤/湿润/可种标记 | 区分“光照合适”和“该格允许种植” |
| 有效期及来源ID | 叠加、到期、结算和存档去重 |

基础阈值起调为深影小于0.15、暖光大于0.6、半光带0.4～0.6。造深影效果必须实际满足判定，不能用`clamp_max=0.15`同时承诺“小于0.15”。雾将光强乘0.5仅是减光：从1.0变为0.5时不能种普通月苔。深影附痕可通过明确的种植条件表达，不能在UI中伪称实际物理光强已变为零。

D03按本轮工程方案统一：具体求值顺序、临界值、来源移除和到期用例见冲突处理方案第5节。生长、敌人索敌、交互提示和Tab预览都读取同一份解析后的光场结果。参数化实现的具体字段可以调整，但不得改变上述语义。

### 3.3 融合与十种附痕

现行融合载体是兵器附痕，不再有两个手持融合道具槽。阴、燃、阳、润四属性两两组合，含自融共十种结果。

- 每把兵器最多一个痕槽；在灯匠处配置，不能战斗中随意重配。
- 已定使用次数为8次有效命中，换季失效。一次攻击多目标、往返判定如何扣次须先定义，不能靠多次碰撞回调重复扣次或重复产出。
- 同源/异源采用本轮次数方案：配方含兵器元素即同源，每次有效动作触发；异源每两次触发一次。八次耐久最多8/4次效果，单次触发保持完整资格、整格范围和规定寿命；详见冲突处理方案第4节。
- 旧“10个独立道具动词/60秒深影囊”的起手、槽位和持续时间已归档；不可与下面的附痕表叠加。

| 配方 | 附痕 | 已选效果 | 还需补的规格 |
| --- | --- | --- | --- |
| 阴+阴 | 影囊痕 | 命中留1格深影，8秒 | 光场条件与叠加 |
| 燃+燃 | 灯芯痕 | 命中格点燃3秒，产生小片暖光 | 燃烧对象、镜像边界 |
| 阳+阳 | 引线痕 | 直线延长2格光，6秒 | 遮挡、光源类型 |
| 润+润 | 露痕 | 命中挂露，手采得1露滴 | 领取ID、单次事件上限、结算边界；不能因重复读档再领取 |
| 阴+润 | 苔痕 | 湿阴影，可种月苔，生长+20% | 已有苗床或指定荒地；临时田一个白昼，到期保护现有株 |
| 阳+燃 | 暖痕 | 干暖光，可种灯铃，生长+20% | 已有苗床或指定荒地；临时田一个白昼，到期保护现有株 |
| 阴+阳 | 二向痕 | 同格阴阳并存，可满足星铃条件 | 显式双光资格；土壤寿命和保株按D02 |
| 阳+润 | 光雨痕 | 照亮、湿润，支持指定荒地种植 | 指定荒地；每区额外临时4格起调，一个白昼 |
| 润+燃 | 雾痕 | 命中留1格雾，光强乘0.5，20秒 | 减光不保证从满光变深影 |
| 阴+燃 | 影烛痕 | 暗处保留灼烧 | 受影响对象与持续时间 |

融合/附痕同时服务种植和守夜。它们不增加兵器基础伤害轴；露痕是显式额外资源来源，不再用“需手采所以不改资源数量”回避经济核算。

### 3.4 装备与形态

装备由元素、族内器形、该兵器的附痕组成。元素决定家族，器形是偏好，无额外形态解锁。无光尘时使用素引灯杆，动作是“拨”，种植为单格操作。

旧“两槽光类5×苔类5=25组合”依赖已废弃的手持融合道具，保留在历史档；不再作为当前组合数、双修优势或验收指标。现行组合表达为16器形×10附痕，实测仍须检查有效组合，不能只凭乘法宣称每组同等有趣。

### 3.5 灯谱与解封

保留最多12节点、浅而宽、免费重置、多途径获取。核心走/冲/格挡/交互及华丽操作不进成长门槛；好感不提供战力或生产效率。

既定节点ID见建造计划。旧节点中`deep_pocket`升级手持深影囊数量、`mist_trail/mist_step`引用旧冲刺道具效果，必须按附痕系统重写后才能验收；不能把已经不存在的道具继续实现。`grass_step`与“冲刺基础穿矮栅栏”的职责也要分开。

已确认的第二轨折扣方向保留：第二轨节点成本减1、最低1点。原点数预算11可得/8需求需要按当前灯和节点重算；旧节点每个仅1点时，折扣不会减少总需求，原“双修8→6”不能成立。实现前先给每节点费用、免费途径、实际可得事件和折扣应用表；以可免费重置、两路线都有解、无点数软锁为验收，不擅自推出新的费用。

八件器具继续采用“完成相关事件即解封”，除入口类内容外提供种植/守夜两条路径。旧表的“用光引解锁融合器”“先完成灯路再取得导光苔枝”存在依赖循环，应画依赖图并给出无需未解锁能力的证明事件。具体替代事件是后续设计工作；不得宣称旧表已闭环。

### 3.6 借光传送

目标必须修复、点亮、亲自到达过；灯路至少有两端。借走普通目标灯火会让光域暂时收缩，影响附近作物；真实母灯是例外，始终保留基础78px照明。原地蓄力2秒，基准约20秒自然恢复。使用中断、灯火不足及多次请求须有反馈。

不按露滴收费，不在战斗中可用，不用金钱缩短恢复。初始消耗量、恢复曲线与省灯节点的叠加需列参数表，不能同时采用旧稿的固定20秒与不一致的回充速率。光域视觉变化必须反映真实条件，灯下的视觉呼吸除外。

### 3.7 动作与输入

#### 动作底层

状态至少区分idle、move、dash、block、strike、interact；数据定义起手、动作时长、恢复和碰撞。采用硬墙、可穿低障碍等碰撞层，不能为穿矮栅栏直接关闭全部碰撞。

冲刺基准起手0.06秒，点按距离不超过0.9R；R=78时为70.2px。旧396px/s×0.18秒=71.28px略超上限，实现时从距离反算时长/速度。120ms输入缓冲、至少400ms衔接窗口为起调值。长按蓄力属于后续可选动作，不混入点按验收。

空间脱战提供低门槛；完美闪避、格挡和情境派生提供操作上限。连招规模封顶3招×2段，派生由敌人/环境情境触发，不靠背输入表；每个器形保留一个可辨的独占动作。零连招、零完美操作也能完成全部内容。冻结帧不使用全局`Engine.time_scale`拖慢作物/UI；有独立关闭选项。

#### 四族十六器形

| 元素 | 器形与动作 | 差异 |
| --- | --- | --- |
| 阴 | 匕·刺 / 飞爪·抓 / 绳镖·收 / 吹箭·暗 | 贴身、拉回、往返、无声远射 |
| 燃 | 斧·劈 / 锤·砸 / 投石索·抛 / 火把·燃 | 破遮蔽、无视格挡、落点范围、持续点燃 |
| 阳 | 枪·突 / 杖·架 / 弓·射 / 戈·钩 | 直线穿透、攻防一体、站定远射、拉近不贴身 |
| 润 | 鞭·扫 / 连枷·绕 / 网·罩 / 镰·割 | 多目标、绕挡、纯控制、贴地范围 |

器具本体不变形；保留真实兵器名，由图鉴解释冷门词。共用轨迹绘制语言，不据“无新贴图”推断美术和测试成本为零。伤害兵器比较完整周期效果；网按控制覆盖、持续与代价验收，不能要求零伤害DPS与其他兵器相等。

#### 输入职责（D04已澄清）

| 操作 | 当前样片/切片A | 全系统目标 |
| --- | --- | --- |
| 移动 | WASD/方向键 | 保留；鼠标短距直走，不寻路；手柄左摇杆 |
| 选择种子 | 1/2、种子卡 | 种子卡/B种子面板；支持键盘焦点和手柄Y面板等效操作 |
| 选择元素 | 无 | 1～4选择元素；不得同时绑定成种子/手持融合道具 |
| 使用/交互 | E/空格 | E按上下文执行，交互目标须明确高亮；不能一次按键又攻击又收获 |
| 冲刺 / 格挡 | 无 | Shift / K或鼠标右键；手柄RB/LT为现有候选映射 |
| 促长 / 移除 | Q/R | 保留场景限定，UI焦点优先 |
| 光域 / 静音 / 暂停 / 全屏 | Tab/M/Esc/F11 | 保留，手账与光域预览不得竞争同一输入事件 |
| 灯下 | 尚未实现 | F或暂停菜单进入；物件选择支持鼠标及手柄吸附 |

切片A保持已熟悉的种子键；只有元素系统接入时才启用完整映射，迁移提示说明变化。本轮原型采用B打开种子面板、J打开手账，手柄Y打开种子面板，物件移除放上下文面板；完整键鼠/手柄映射和事件优先级以冲突处理方案第6节为准。

### 3.8 五区世界

| 区域 | 核心用途 | 内容预算 |
| --- | --- | --- |
| 月苔灯圃 | 基础明暗种植 | 12格、3灯 |
| 月色水池 | 倒影光 | 10格、2灯 |
| 灯路谷 | 导光连接 | 8格、4灯，含3个灯路节点 |
| 星夜花园 | 暖杏+月青双光 | 10格、2灯 |
| 长夜边界 | 可选守夜 | 6格、2灯 |

合计46格、13灯。三盏主灯与全区域灯必须用明确ID区分，不能在扩大灯表后继续用全局`restored == 3`代替主线进度。

采用分区加载，各区基准960×640；切区保留状态、安全出生点和朝向。程序绘制不保证加载瞬时，应实际测量。入口坐标需做碰撞和可到达性检查。

主线零必解谜题门。灯路谷有冗余苔枝、多解或可代做/跳过方案；番外承接可选谜题。双光重叠至少覆盖一个完整种植格，不能只做画面上的交叠。最早守夜入口按D01从首日黄昏开放，不以三灯全亮封死整条收入路线。

### 3.9 守夜与结算

守夜地点是岔路；玩家自愿敲钟，设置可关闭夜钟，中途可退出。敌人只攻击灯与遮蔽物，角色没有HP。雾蛾追光、光噬追暗，详细出招表见数值表。难度主要通过雾、潮汐、湿气、风向和时间压力改变条件，不随角色成长自动抬高敌人数字。

| 结果 | 判定 | 评级 | 余温 | 日历 |
| --- | --- | --- | --- | --- |
| 胜 | 撑到结束且仍有亮灯 | S/A/B/C | 1份 | 进入下一日一次 |
| 败 | 灯全熄 | C | 0份 | 进入下一日一次 |
| 弃 | 主动离开 | 无 | 0份 | 进入下一日一次 |

以上余温规则不变，旧“灯熄也给余温”不再生效。基础夜露起调为胜/败36、弃0；实际产生的临时田/挂露胜败提交、弃场撤销，主动耗材不退款。具体白名单及一次性事务以冲突处理方案第4节为准，数值表记录经济验证条件。

战后不能重刷同一结算ID；加载同一场前后存档不能重复领取。训练场不默认发放正式奖励，其范围与开放时机在M5前明确。

### 3.10 NPC与交易关系

四位常住角色：门灵苔婆婆、灯匠钉铃、夜行旅人、影猫咔嗒。好感只给故事、外观、图鉴与环境表现；不加生产/战斗数值，不影响价格，不作为器具门槛。

人物各三段故事，对应好感3/4/5。NPC约定是自愿交换，最多三张夹页；不能把未完成变成强制追踪列表。影猫不做生意，四位NPC不等于四个商店。

### 3.11 状态归属

| 状态 | 普通游玩 | 守夜局内 | 结算/持久化 |
| --- | --- | --- | --- |
| 真实资源、原苗床作物、修复状态 | 正常修改 | 不因战斗损失而扣减 | 保留原值，加明确的合法收入 |
| 战斗灯火、弹药、遮蔽物 | 不存在或仅布置预览 | 镜像修改 | 丢弃损耗，不整份写回 |
| 余温 | 消耗与过期 | 尚未获得 | 胜利一次发放，不混入永久库存 |
| 痕造田、挂露 | 按世界交互生成 | 记录候选结算事件 | 胜败提交、弃不提交；土壤一个白昼，到期封床保株；挂露需手采 |
| 痕耐久、已服光尘 | 消耗品语义 | 按唯一有效动作记录消耗 | 胜败弃均不退已主动使用的耗材；一次事件不能重复扣 |
| 日历 | 普通白昼推进 | 独立夜间阶段 | 胜/败/弃都只跨日一次 |
| 故事与引导标记 | 首次事件写入 | 只登记合法事件 | 回看不重复奖励；不计求助羞耻统计 |

### 3.12 系统联动

保留五条关系：光场决定种植位置；经营布置提供守夜镜像；融合/附痕改变光场与动作后果；世界事件解封器具；资源交易连接两条收入路线。

星铃的钉痕、苔毯的留痕等联动意图保留，但需要转写为现行作物/附痕状态，不能继续依赖旧手持道具。按“在种植与守夜各解决什么问题”验收，而非用旧14/14、25组合等数量证明已经平衡。

### 3.13 光尘与战后余温

普通游玩时，亮灯且灯火饱和可以凝积灯芯屑，借光会暂停这段积攒。灯下/离线不额外产灯芯屑。灯芯屑与材料制成四种光尘：

| 光尘 | 经营侧意图 | 守夜侧意图 |
| --- | --- | --- |
| 燃 | 三次促长免露滴 | 格挡窗口×1.5、反震范围+1格 |
| 润 | 种植/收获范围+1格 | 冲刺距离+20%、雾相关持续加成 |
| 阴 | 加深阴影条件 | 索敌距离-30%、完美闪避窗口+50% |
| 阳 | 加深暖光条件 | 射程/视野+20%、引线范围加成 |

这些是起调效果；冲刺上限、范围等必须注明是基础值还是加成后上限，不能各自通过测试却合起来越界。只允许一种生效，切换放弃剩余效果；不改变作物单次收获数量。D05已采纳：夜苔仅冬季，回声铃仅春秋，任何光尘都不豁免季节资格。

余温是省去攒料的一份等价光尘，不与自带光尘叠加。只在胜利发放，一夜一份、每季最多8份、评级不改数量，作用于接下来的白昼，到期失效。单独记录余温与到期点，不能放进无期限库存后又宣称不可囤。

### 3.14 器具封印

器具上限八件：灯谱、手提灯、融合器、借光石、导光苔枝、碾子、夜钟、背灯架。已完成事件作为教学确认，不要再叠材料、等级和好感锁。

解封依赖图需排除循环；既定种植/守夜双途径方向不变。夜钟按已采纳D01从首日黄昏开放。名称按D07暂用现名，稳定ID不随显示名改变。

### 3.15 巡灯路线 离线生长 静观

- 巡灯路线：玩家走过并录制，最多3条；重走遇敌、事件或可交互目标停下，不能自动种收；守夜禁用。不做AI寻路。
- 离线生长：仅推进已种作物，最多720秒；不推进日历、收获、资源和守夜奖励。具体加载规则见存档契约。
- 静观：20秒无操作自动隐藏UI，日历仍按普通游玩走；再站60秒提示可进入灯下。移动退出，不弹任务清单。

### 3.17 灯下陪伴

非守夜状态下，在点亮的固定灯附近可按F或通过暂停菜单坐下；隐藏HUD、角色坐姿、镜头轻漂、视觉光域呼吸、伴灯曲与微小环境事件。作物照常长，白昼计时与`phase_elapsed_seconds`均冻结，灯芯屑/资源不自动增长；不能借灯下跳过战斗结算。

可重复的交互包括添灯芯、摸猫、摇灯铃、拨萤火、看池水、翻手账；不补charge、不收作物。本轮原型遵守零后果护栏：灯下摸猫不加好感，也不占用普通摸猫日额度；禁止隐藏UI时继续播种、收获、促长、领取挂露、交易或切元素。

移动/退出操作立即恢复普通控制，无确认框。本轮原型记忆灯ID、坐姿和镜头偏好，不移动角色到历史坐标；普通游玩失焦暂停、灯下失焦维持，回焦不自动退出，系统休眠暂停。该方案明确取代旧“点击画面外退出”的矛盾表述，待实机检验，详见冲突处理方案第7节。

伴灯曲淡入8秒、淡出3秒，四季变体，独立音频播放器；回归短句按本次停留时间选择，不形成在线时长统计或奖励。视觉呼吸不动生长判定。

可降低动态重绘频率并实测后台帧率/CPU/GPU。当前farm约12次每秒重绘不等于整个游戏只运行12fps，不能据此承诺“不烫机、不需要优化”。

### 3.18 方向 引导与求助

三层引导：今日页三条方向信息、首次机制一句操作提示、NPC主动/被动求助。提示按玩家正在尝试的动作投放，不按春夏秋冬强制分期。首次提示只自动弹一次，但操作速查和故事回看始终可用。

卡住约3分钟无有效进展时给温和提示，不把灯下、暂停和主动静观计入卡住。玩家随时可找NPC问，逐级从方向、具体线索、操作到代做；不扣资源、不影响评级、不记录“不求助成就”。系统内部可保留当前提示层级，不能把“无羞耻记录”误解成无法实现阶梯状态。

主线不设必解谜题；番外采用冗余物、多解、可跳过。字体和提示长度按组件宽度实测，不能用全局20字上限保证所有窗口都放得下。

### 3.19 分享与存档搬运

本体不承载论坛、好友、联网托管。灯语是离线只读布局展示；留言灯为后续备选，只在主动导入时出现，三段短语、默认关闭、7日变旧14日消失、最多20条，不进主线。

灯语采用本轮9字符协议初案：8载荷+1校验，显示固定模板的作物分类/灯状态示意；不承诺精确复原任意装饰、所有作物类型或临时田。32字符字母表、40bit预算、错误检测能力和拒绝条件详见冲突处理方案第8节。协议尚未发布，需固定测试向量；只读展示仍需输入校验。

箱子导出完整存档为`.moss`，导入先校验后替换、失败不动原档。本轮协议初案是MOSS魔数、版本、长度、SHA-256摘要和UTF-8 JSON，详见冲突处理方案第8节及存档契约；校验只用于发现损坏，不声称防手改。

### 3.20 混合游玩的定位

保留效率、容错、认知三方面：余温省准备、免费重置与足够解锁途径降低选错成本、按需引导避免同时灌输。第二轨点数折扣需等新节点费用表闭合，不能沿用无效的8→6算式。

不做季内职业声明，不削弱单一路线，不用“25组只有双修能用”描述已废弃的装备系统。混合路线的实际优势以可选择的活动与搭配解释，并通过路线测试比较时间。

### 3.21 交易与持续更新

婆婆提供种子/服装，钉铃提供材料/工坊，旅人提供装饰与消耗品；猫不卖商品。价格不受好感影响，无每日刷新、倒计时、限时折扣或“新品”催促。材料/非应季种子可以应急购买，但不能成为比正常玩法更优的批量产出路径。

保留材料溢价至少×5、季节外种子至少×3的起调约束，仍需定义基准价。购买非应季种子不自动赋予生长资格，D05已取消稀有作物跨季豁免。

装饰包括灯具外观、地面纹样、围栏、环境布置和服装，不加数值、不计100%。一次性雾、预备灯芯、催熟粉、灯芯屑和叙事信件继续作为候选商品；“省一次材料”也须进入收支表，不用高价标签代替验算。

基线更新为装饰6～8件和轶事1个。新机制/人物允许加入，但要过准入：不引入新的数值成长轴、优先改判定/空间、至少让一件旧内容更有用、优先复用输入。新NPC不破坏四人围绕缺席者的结构，好感仍只给情感内容。

### 3.22 黎明之后

保留有限收束：达成黎明后30个游戏日，最后一轮角色告别，再进入可无限游玩的自由模式。按每白昼12分钟，30日白昼至少6小时，原2～3小时估计撤销；不是实时30个自然日。

自由模式仍有季节、装饰、番外回看、灯下陪伴。最后一次剧情不移除尚未看的NPC故事或回看入口；新增章节可扩内容，但不能把已有“故事讲完了”变成每日任务。

### 3.23 内容扩张准入

保留原子组合方向：点光、线光、倒影、双光、遮挡、移动光、呼吸光、无光；平地、窄缝、高台、水面、镜面、滑面、藤蔓、石堆；追光、追暗、追声、伏击、分裂、搬运。

移动光、镜面等是未来候选，不是已经实现。镜像谷/响苔/呼吸光/衔灯鸟/全黑洞窟是备选内容顺序，不构成发布承诺。每次先验证旧内容如何获得新用途、可访问替代提示是否充分，再决定是否制作。

## 4 存档与时间主定义

存档结构只在[存档契约](save-contract.md)维护。本文件不复制另一套JSON。

| 模式 | 累计白昼时间 | 当日白昼计时 | 作物 | 日历/结算 |
| --- | --- | --- | --- | --- |
| 普通白昼/静观 | 增加 | 增加，到720秒转黄昏 | 按条件增长 | 此时不直接跨日 |
| 黄昏 | 不变 | 停在边界 | 按条件增长 | 独立30秒；未选择默认睡觉 |

| 灯下 | 不变 | 不变 | 按条件增长 | 不跨日、不自动开始守夜 |
| 离线 | 不变 | 不变 | 仅既有作物，最多720秒 | 不跨日/换季/奖励 |

`calendar.play_seconds`是累计有效白昼时间；`day_elapsed_seconds`在新日归零。黄昏/夜有独立阶段时间。四季每季8日，一年32日；季节由游戏内阶段结算推进，不看系统日期。

边界事件必须幂等：一次黄昏不能既睡觉又开始守夜，一次夜间结束不能日历+2。灯下恢复时从原阶段继续，不靠补算挂机时长跨日。

## 10 叙事与表现

### 10.1 世界前提

长夜是自然现象，无反派、天灾或拯救世界任务。玩家是接班的巡灯人；上一任不出场，不交代去处，不明写身份。灯是照路、育物和生活记忆。四位NPC从不同角度留下同一个缺席者的痕迹。

### 10.2 主线

修灯露出远处石座和灯路，连接五区。环境给远程方向，今日页和首次提示给当前行动，不能只依赖远方微光。保留“母灯永不熄灭”的目标设计；当前代码仅保证它已修复，仍可开关，该目标尚未实现。本轮方案在M1内容层禁止关闭真实母灯，借光保留基础78px照明；战斗镜像不豁免。M0仍原样迁移旧开关，不把玩法改动藏在格式升级中。

### 10.3 日循环与季节

普通白昼12分钟、黄昏30秒、守夜45～60秒或睡觉跳过。四季各8日；没有白昼加速。各作物生长资格与速度倍率分开列，见数值表；冬季五种可用；D05已确定夜苔仅冬季、回声铃仅春秋。

### 10.4 开局体验

前10分钟依次接触移动/交互、阴影月苔、暖光灯铃、修灯与远方。切片A不教尚未实现的冲刺或守夜。普通12分钟白昼不能同时宣称第9分钟自然进入首次黄昏；若以后需要专门的序章时长，应另作明确设计。

### 10.5 黎明

五区灯路连通且指定三盏主灯修复时触发。用世界画面和声音表现黎明，可继续游玩；NPC故事不作为触发前置，因此文本必须有黎明前后适用版本。整图变亮先区分视觉表现和实际生长光场，不能瞬间抹掉所有阴影种植途径。
