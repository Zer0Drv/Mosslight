## 0. 先看这三条（评审重点）

| # | 我的核心决定 | 为什么 |
| --- | --- | --- |
| 1 | **四个 NPC 全都是「上一任巡灯人」留下的痕迹** | 一句话把所有人物串成一个故事，不用做任务链 |
| 2 | ✅ **已定**：**上一任巡灯人永远不明写**（不出场、不交代去处） | 留白比反转高级；玩家拼出来的比被告知的更留得住 |
| 3 | **苔婆婆的"重复"是有意义的** | 她三段故事里的转变（详见 2.1）就是全篇最动人的一处设计 |

✅ **第 2 条已采纳**（主人 2026-10-30）：**不点破**。全篇只给线索，答案留给玩家拼。

**由此定下三条写作纪律**（下文所有 NPC 台词都必须遵守）：

1. **不许出现"他"的关系说明** —— 不说"他是上一任"、不说"你儿子"、不说"那个人"
2. **线索只能是物件、动作、数字** —— 钥匙 / 灯芯 / 压痕 / 数到几 / 走哪条路
3. **每段故事都不许封闭** —— 至少留一个玩家能追问、但游戏永远不答的问题

## 1. 命名规则

### 1.1 四个字根

四个字根是命名的主要语汇来源。现有「星铃」「钉铃」等名称也使用形态、声音与动作字，不把这四字当作排他的字典：

| 字根 | 含义 | 例子 |
| --- | --- | --- |
| **苔** | 会生长、会记录时间的东西 | 月苔、夜苔、苔婆婆、苔灯 |
| **灯** | 人做的、会亮的东西 | 灯铃、灯芯、灯路、钉铃 |
| **露** | 从东西里出来的资源 | 露滴、浮露苔、夜露 |
| **夜** | 世界的状态，不是敌人 | 长夜、夜苔、夜露、夜钟 |

### 1.2 三条硬规则

1. **不出现外文词、不出现现代词**（没有"系统""能量""系数""任务"）
2. **不出现"魔法""法术""能量"**——光就是光（对应路线图「光照与作物判定」「系统联动」）
3. **名字里不解释名字**——不做"XX之XX"的复合命名

### 1.3 名称状态

- 「苔婆婆」是对外称呼；内部创作背景保留本名「苔九娘」，不在台词中解释身份关系。
- 「钉铃」按工作得来的外号使用，不改作姓氏或本名。
- 作物、地区、器具、动作和痕暂用现名，见第 10 节。此工作口径已采纳；后续文本调整不改变稳定 ID，不构成工程阻塞。

## 2. 四个 NPC

**共同点**：四个人都在等/守/找同一个人。**那个从不出场。**

### 2.1 门灵 · 苔婆婆

| 项 | 内容 |
| --- | --- |
| 本名（作者背景） | 苔九娘；对外仍称苔婆婆 |
| 身份 | 镇子最后一位「守门人」，住小屋旁 |
| 与巡灯人（作者背景） | **上一任巡灯人的母亲**，玩家文本不直说 |
| 为什么留下（作者背景） | 儿子的灯还亮着，她不肯走 |
| 外貌 | 个子矮，围裙口袋里总有种子；拄一根比她高的木杖（其实是大号灯扳手） |
| 说话风格 | **短句 + 重复 + 突然想起**。三句话里必有一句是重复前一句。**这是她记性不好的表现，也是她的节奏** |
| 口头禅 | 「吃了没有」「灯还亮着」 |

**三段故事**

| 好感 | 内容 | 关键台词 |
| --- | --- | --- |
| 3 | 她说起扫门与换过的扫帚，短句里有重复 | 「扫帚换了……四把。四把。」 |
| 4 | 她记得过去有人数灯，但不说身份 | 「以前不是我数。不是我数。」 |
| 5 | 她把数灯这件事交给玩家；灯已亮与未亮时须使用对应文本 | 「我数不动了。你数吧。」 |

> **设计要点**：好感 5 的第三段不再重复。前两段用重复铺垫，第三段以「我数不动了。你数吧。」收束。正文、播放顺序和灯已亮时的变体见文案接入表。
> 这是全篇最省力、也最有效的一处人物弧光——**不靠 CG，靠标点。**

### 2.2 灯匠 · 钉铃

| 项 | 内容 |
| --- | --- |
| 本名 | 不明，全镇只叫他钉铃 |
| 身份 | 灯匠。学徒出身，手上有旧伤 |
| 与巡灯人 | **上一任的同期**，但他一直自称"学徒" |
| 为什么留下 | 「灯还没修完。」 |
| 外貌 | 手上有三处烫疤，永远戴皮手套；帽子挂着小铃（所以他走路很轻） |
| 说话风格 | **像在报工序**。一句话里必有数量和顺序，从不说"大概""可能" |
| 口头禅 | 「先……再……」「这个不行，得换」 |

**三段故事**

| 好感 | 内容 | 关键台词 |
| --- | --- | --- |
| 3 | 他先报工序，再讲灯的形状与来处 | 「先钉住，再转半圈。别用蛮力。」 |
| 4 | 作者背景：上一任曾替手抖的他挡过一次；可见文本不解释身份 | 「以前有个人替我挡了一下。」 |
| 5 | 他不修完不走，因为"灯是有数的" | 「少一盏，我睡不着。」 |

> **设计要点**：他用职业动作回避情绪。第三段保持短句，不在「少一盏，我睡不着」之后解释感情；灯已修齐时转向工具还要继续用，具体变体见正文。

### 2.3 夜行旅人

| 项 | 内容 |
| --- | --- |
| 本名 | 无 |
| 身份 | 不明。**只在三灯全亮时出现** |
| 与巡灯人 | 不明 —— **但不明说才是重点** |
| 为什么留下 | 他不是留下，他是**回来看看** |
| 外貌 | 斗篷，脸看不清。背一个**空布袋**——走的时候袋子会鼓一点 |
| 说话风格 | **不说话，只留东西**。放下一样东西，退后，等你捡 |

**他的"三段故事"是三件被留下的东西**（不是对话）

| 好感 | 留下的东西 | 玩家能想到的 |
| --- | --- | --- |
| 3 | 一把旧钥匙，**打不开镇上任何一把锁** | 那是南边的门 |
| 4 | 半截灯芯，**和母灯的一模一样** | 他从母灯上剪的？还是母灯是他点的？ |
| 5 | 一张没有字的纸。**对着灯看，有压痕** | 写过，又擦掉了 |

> ✅ **已定：不点破。**
> 一旦明说，玩家就从"我在拼一个故事"变成"我在看一个答案"，而后者只值一次。
>
> **所以旅人永远不会有一句确认性台词。** 他能做的最多是把东西放下、退后、等你捡。
> 玩家若把三件东西（旧钥匙 / 半截灯芯 / 有压痕的白纸）放在一起看，答案会自己浮出来——**但那必须是玩家自己放上去的。**

### 2.4 影猫 · 咔嗒

| 项 | 内容 |
| --- | --- |
| 身份 | 上一任巡灯人的猫 |
| 为什么留下 | 它还在**巡逻** |
| 外貌 | 全身黑，只有眼白和爪尖是月青色；尾巴尖有一小撮灯芯灰 |
| 说话风格 | 不说话。**用位置说话**——它坐哪，你就该看哪 |

**三段"故事"（通过行为，不是台词）**

| 好感 | 行为 | 玩家看到的 |
| --- | --- | --- |
| 3 | 它每天走同一条路 | 那是上一任的巡逻线 |
| 4 | 它会在某盏灯下面坐很久 | 那盏灯是空的 |
| 5 | 它开始跟着你走 | 它接受你了 |

> **为什么它是猫而不是人**：全篇所有"人的事"都由三个成年人用克制的方式讲，**需要一个不会克制、也不会说话的角色来承载温度**。猫就是那个角色。

### 命名逻辑

```
月苔 → 月 / 苔      （形态 + 字根）
灯铃 → 灯 / 铃      （光 + 形状）
夜苔 → 夜 / 苔      （时间 + 字根）
影苔 → 影 / 苔      （状态 + 字根）
浮露苔 → 浮 / 露 / 苔（动作 + 资源 + 字根）
星铃 → 星 / 铃      （光点 + 形状）
```

**规律**：名字里如果带「苔」，它长在地上；带「铃」，它挂在枝上。

当前名称见第 10 节；旧备选名保存在整理前归档，不再与当前工作名称并列待选。

## 7. 器具与「引」

### 器具只有 8 件，都不变形

| 器具 | 身份 | 参与「引」吗 |
| --- | --- | --- |
| 灯谱（手账） | 记录 | ❌ |
| 手提灯 | 光 | ✅ 唯一的「出口」 |
| 融合器 | 配 | ❌ |
| 借光石 | 行 | ❌ |
| 导光苔枝 | 铺 | ❌ |
| 碾子 | 磨 | ❌ |
| 夜钟 | 开关 | ❌ |
| 背灯架 | 载 | ✅ 远行时带灯 |

> **器具是工具，不是武器。** 全篇没有一把真刀。你手里唯一的"兵器"是灯引出来的光。

### 四族十六把

**每种元素从灯里引出的东西不一样——因为每种光照出来的东西本来就不一样。**

#### 阴 · 暗器系（短、藏、收）

| 器形 | 动作 | 一句台词式印象 |
| --- | --- | --- |
| **匕** | 刺 | 最短，也最快 |
| **飞爪** | 抓 | 抓回来 |
| **绳镖** | 收 | 出去，再回来 |
| **吹箭** | 暗 | 你听不见它出鞘 |

#### 燃 · 破坏系（钝、重、燃）

| 器形 | 动作 | 一句 |
| --- | --- | --- |
| **斧** | 劈 | 一下，开 |
| **锤** | 砸 | 挡不住 |
| **投石索** | 抛 | 转三圈再撒手 |
| **火把** | 燃 | 点亮，也点火 |

#### 阳 · 长兵系（直、远、正）

| 器形 | 动作 | 一句 |
| --- | --- | --- |
| **枪** | 突 | 一条直线，穿过去 |
| **杖** | 架 | 打，也挡 |
| **弓** | 射 | 要站定 |
| **戈** | 钩 | 勾过来，但不沾身 |

#### 润 · 软兵系（缠、绕、罩）

| 器形 | 动作 | 一句 |
| --- | --- | --- |
| **鞭** | 扫 | 一大片 |
| **连枷** | 绕 | 绕过去 |
| **网** | 罩 | 不伤，只困 |
| **镰** | 割 | 最老的农具 |

### 同一把，两边都用

> 这十六把**每一件都是真东西**——它们本来就既是兵器，也是农具。
> 镰是割麦的，连枷是脱粒的，网是捞的，斧是劈柴的，弓是打猎的。

所以「对着作物按 E」和「对着敌人按 E」用的是同一把，只是对象不同：

| 器形 | 对着敌人 | 对着作物 |
| --- | --- | --- |
| 镰 | 勾割 | 割一片 |
| 斧 | 劈碎 | 砍倒整丛 |
| 网 | 罩住 | 防虫、遮光 |
| 弓 | 射 | 射落高处果子 |
| 飞爪 | 拉过来 | 抓高枝 |

**没有"战斗专用的兵器"，也没有"农活专用的工具"——只有一双手。**

### 素引：一根灯杆

没有生效的光尘时，你手里就是一根灯杆，只能**拨**；这与固定苔灯的开关无关。

- 打一下，或者拨一下苗
- 拨一下苗，就是点收

> 灯匠说过一句：「素引也能干活。就是慢。」
> 这是全篇唯一一次解释机制的台词——放在他嘴里，因为符合他"报工序"的习惯。

### 痕：融合与兵器的接口

融合不再"造道具"，而是**往兵器上系一道痕**。一把兵器只挂一道痕，8 次命中后耗尽。

> **已采纳边界**：D02 采用临时造田。在已有苗床或指定荒地留下种植条件，战斗结算后保留一个完整白昼，不永久增加固定苗床。露痕挂露可手采得真实露滴；领取、去重和到期作物保护按[设计规范](design-mosslight-roadmap.md)执行。即时光效与土壤许可分别计时，不用诗性描述代替判定。

| 痕 | 打过的地上会变成 |
| --- | --- |
| **苔痕** | 又湿又暗 → 能种月苔 |
| **暖痕** | 又干又暖 → 能种灯铃 |
| **二向痕** | 亮着也暗着 → **能种星铃**（它要两种光叠在一起） |
| **光雨痕** | 又亮又湿 → 荒地变良田 |
| **雾痕** | 一小片看不清的雾 |
| **影烛痕** | 暗，但烫 |
| **影囊痕** | 暗下去一小块 |
| **灯芯痕** | 烧一小会儿 |
| **引线痕** | 光多走两格 |
| **露痕** | 挂一颗露，手采得 1 露滴；每颗只领一次，不因回看、读档重复领取 |

**同源才顺手**：配方包含兵器元素即同源，每次有效动作触发；异源每两次有效动作触发一次。减半指八次耐久最多触发四次，单次效果不出现半格、半滴或半天；具体事件规则见[冲突处理方案](issue-resolution.md)第4节。

## 8. 文案语气指南

### 能说

- 「灯还亮着。」
- 「你回来得正好。」
- 「先钉住，再转半圈。」
- 「雾散了又聚。」

### 不能说

| ❌ 不能说 | 为什么 |
| --- | --- |
| 「恭喜解锁 XX！」 | 感叹号会把温度打散 |
| 「完成度 80%」 | 数字会把世界变成表格 |
| 「感谢游玩」 | 客气是陌生的开始 |
| 「XX 之 XX」 | 复合命名会显得像网游 |
| 「系统提示」 | 世界之外没有系统 |

### 三条写法

1. **名词 > 形容词**（「雾」比「朦胧的雾」好）
2. **陈述 > 感叹**（「灯灭了」比「灯灭了！」好）
3. **留白 > 解释**（「少一盏，我睡不着」之后不要加解释）
