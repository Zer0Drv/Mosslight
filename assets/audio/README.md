## 灯下伴灯曲（已合并切片 A）

`under_lamp.wav` 位于本目录，是16秒、22050 Hz、16位PCM、单声道的稀疏钟音循环，由 `generate_companion()` 原创合成。它使用独立的 `LampLullaby` 播放器，目标音量−20 dB；进入灯下模式8秒淡入，离开3秒淡出后停止，不占用反馈音效或脚步声池。M同时控制伴灯音乐静音；快速离开再进入会取消旧的淡出停止回调，避免新播放被中断。普通游玩不启动伴灯循环，退出后的短淡出只保留过渡尾声。包含此曲后，当前共19个运行声音文件。


`ForestAudio` 保持环境播放器独立，交互最多6声复音；脚步另用独立播放器，不能切断修灯和收获的尾音。`update_footsteps(world_position, delta)` 按碰撞后的实际位移触发，快速渲染产生的单帧静止不会重置步距；靠墙、停步、传送及静音不会持续产生脚步。主入口只在未暂停时调用它。按 M 一并控制环境与反馈，不更改项目共享音频总线。

## 复现与检查

```powershell
python tools/generate_audio.py
```

默认同时重建 `under_lamp.wav`、v2 文件和 `v2/manifest.json`。旧7个 WAV 的原合成器仍保留，可用 `python tools/generate_audio.py --legacy` 复现。默认命令不会改写旧7个文件。

完整生成参数在脚本内：固定随机种子族 `310000`、逐事件音高/延迟/包络、环境的24秒整数周期调制、伴灯草稿的32秒循环音符与环形回声。清单记录每文件用途、运行状态、时长、声道、峰值、RMS、直流偏移、循环接缝、SHA256及大小。

生成时自动检查实际量化后的PCM：

- 全部非静音，峰值不超过 −6.37 dBFS（交互素材），无满幅削波；直流偏移小于 0.002。
- 短音首尾均为0，包络衰减到静音。
- 两个循环的首尾跳变小于0.02，且不超过文件内部的最大相邻采样跳变。环境循环实测0.0057373，伴灯草稿0.00030518。
- v2 20个 WAV 合计7,197,560字节；每文件哈希可与清单核对。

这些指标证明文件格式、信号及循环边界满足工程约束，不代替最终耳机/扬声器试听。可先打开 `v2/audition.wav` 按顺序听：3个脚步 → 选种 → 播种 → 露养 → 月苔收获 → 灯铃收获 → 移除 → 点灯 → 熄灯 → 无效操作 → 光域 → 暂停/继续 → 修复 → 三灯完成。环境、已接入的 `under_lamp.wav` 和备用伴灯草稿可分别打开试听。
